# MarketAI

This repository has been reset to a neutral Next.js foundation so the project
can move in a completely new direction without carrying over the previous
MarketAI product assumptions.

## Current State

- Next.js App Router
- TypeScript
- Tailwind CSS
- React 19
- A single landing page that marks the project as a fresh start

## Local Development

```shell
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available Scripts

- `npm run dev`: start the local development server
- `npm run build`: create a production build
- `npm run start`: run the production server
- `npm run lint`: run ESLint
